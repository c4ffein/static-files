# pyscotch

Files behind the [Scotch tracker](https://c4ffein.github.io/pyscotch/analysis/) of
[PyScotch](https://github.com/c4ffein/pyscotch). This repository allows force-pushes: link through a
commit-pinned URL and check the sha256.

- `external_reports/scotch-bug-review-7-oct-2026-1c64e542-dc42-4f69-b178-bc8b576c5a58.pdf`: Robert Perry's
  review of Scotch 7.0.16, published with his agreement and the Scotch maintainer's. 808 KB, sha256
  `080bd409759807a301a7db2af3ee03a85aecd6ff36396ef1cc4cd6397ffcedf8`.
- `pyscotch_reports/pyscotch-scotch-7.0.17-handoff-clean.tar.xz`: the process behind PyScotch's analysis of
  7.0.17 (agent prompts, test logs, the patch series as a git bundle, the subagent transcripts), for whoever
  picks it up next. Start with `HANDOFF.md`. 15 MB, sha256
  `cf8e4d4b42f237ff3a388e945d308ffa39d4fba413950060867a97c963949c51`.
