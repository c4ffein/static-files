On a également le replay de pyscotch doctor.
Juste après l'installation, on le lance une première fois, et sur la wheel, il ne détecte aucun problème.
Ensuite, on active le mode parallèle avec la variable d'environnement, et là, il nous dit que la bibliothèque n'est pas chargée, il nous donne le fichier manquant, et surtout, il nous donne la commande exacte qui permet de le construire.

C'est quelque chose que j'ai voulu dès le début, pour les humains comme pour les agents.
On n'a pas à aller chercher dans un README ce qu'il faut faire, l'outil le dit lui-même, et un humain ou un agent qui tombe sur cette erreur peut enchaîner tout seul sur la commande suivante.
